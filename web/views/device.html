Panduan perintah device (klik untuk buka)
Tarik Transaksi = perintah device upload ulang tap yang tertahan (masuk ±1 menit). Tarik Data User = tarik data user + template wajah dari device ke server. Sync Pegawai ke Device = dorong data pegawai terpilih ke device (pengganti klik manual di BioTime). Catatan: user/wajah di device mengikuti area — device hanya menampung pegawai yang terdaftar di areanya. Bila PIN user di device tidak sama dengan NIP di server, BioTime membuat pegawai baru (duplikat) — cek Master Pegawai sesudahnya. Operasi destruktif (hapus data device) tetap dilakukan dari BioTime langsung.
